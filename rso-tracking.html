RSO Tracking — Active-Team Update

This utility generates a full updated rso-tracking.html file. It hides inactive Route Techs and Route Tech Leaders from standard RSO views, filters, and printed reports. Their existing quote records remain in Supabase.

Alternative: If GitHub downloading fails, save the current rso-tracking.html file from GitHub to your computer, then select it below.

Ready. Click “Generate from GitHub” to create the updated webpage file.

After downloading the updated file

  1. Open rso-tracking.html in GitHub.
  2. Choose Edit this file, replace the contents with the downloaded file, and Commit changes to main. Alternatively, upload the updated file with the same name to replace it.
  3. Refresh RSO Tracking after GitHub Pages finishes publishing.
This utility does not log in to Supabase or GitHub, send data to a server, or modify your live webpage itself. It only downloads and modifies the public HTML source in your browser.
