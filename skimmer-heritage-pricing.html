Two independent costs, one estimating source. Heritage-linked products use the vendor cost in the latest approved Skimmer Products export. All other Molinari inventory parts use their latest recorded receiving cost, falling back to the part master cost when no receipt exists. This import never edits stock quantities, FIFO lots, purchase costs, or previous JobTread quotes.

Monday workflow

  1. Allow Skimmer's Heritage vendor-cost refresh to complete, then export the full Products list as CSV.
  2. Drop the file here and review how many Heritage items match Molinari inventory.
  3. Confirm import. The Data Import Center marks this step complete for the week.
  4. The estimating-cost feed is then ready for the separate database-to-JobTread nightly catalog synchronization. That synchronization must be enabled and validated independently.
