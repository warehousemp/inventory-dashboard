1. Projects Issues Bid Request Projects sends the JobTread Bid Request to Molinari Warehouse.
2. Warehouse Checks Inventory Ken reviews On Hand, existing commitments, and Available to Commit.
3. Projects Updates Bid Projects removes items Warehouse cannot supply and leaves only approved inventory items.
4. Warehouse Accepts Bid The accepted Bid Request becomes the final list Warehouse will fulfill.
5. PO Commits Inventory When Projects converts the Bid Request to a PO, inventory is reserved—not yet physically issued.
